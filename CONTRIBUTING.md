# Contributing to StickyPad

Thank you for your interest in helping improve StickyPad! This project is maintained during personal free time, and contributions from the community are warmly welcome.

---

## 🛠️ Setting Up Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Karnozetrex/stickypad.git
   cd stickypad
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the app**:
   ```bash
   npm start
   ```

4. **Run the automated test suite**:
   ```bash
   npm test
   ```

---

## 🐛 Reporting Bugs

If you encounter unexpected behavior, crashes, or visual glitches:
- Check existing issues on GitHub first to ensure it hasn't already been reported.
- Open a new issue using our **Bug Report** template.
- Include clear steps to reproduce the issue, your operating system and version, and any relevant error messages.

---

## 💡 Suggesting New Features

Ideas and suggestions are always welcome! When proposing a feature:
- Describe the motivation behind the suggestion and how it improves the daily note-taking experience.
- Keep in mind StickyPad's philosophy: lightweight, distraction-free, privacy-first, and zero unnecessary bloat.

---

## 📥 Submitting Pull Requests

- Keep pull requests focused on a single bug fix or feature enhancement.
- Follow existing code patterns (vanilla JavaScript, modular structure, strict Electron security defaults).
- Run `npm test` before submitting to verify that all automated checks pass.

Thank you for making StickyPad better!
